# Jehlum Cafe — From Mountain to Table

A rich, interactive storytelling web experience for **Jehlum Cafe** (Brooklyn, NY), built with React, Framer Motion, and Tailwind CSS.

## Features

- **Smooth River Animation**: SVG mask scroll-driven river path representing the flow from mountain to table.
- **Scroll-Linked Interactions**: Framer Motion scroll reveals, parallax scenes, and atmospheric backdrops.
- **Responsive & Atmospheric UI**: Custom color palette inspired by Kashmir & Punjab waterways and culinary traditions.

## Tech Stack

- **React 19**
- **Vite 6**
- **Framer Motion**
- **Tailwind CSS v4**

## Getting Started

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build
```bash
npm run build
```

### Preview
```bash
npm run preview
```
